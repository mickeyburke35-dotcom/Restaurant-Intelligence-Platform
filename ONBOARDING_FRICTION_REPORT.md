# Onboarding Friction Report

Use this template during first-time user testing for the Restaurant Intelligence Platform. Focus on whether a new Owner/Admin, Manager, or Analyst can sign in, understand the agency workspace, add or select a restaurant client, import approved reviews, generate traceable draft insights, and prepare a report without unclear copy or unsafe assumptions.

## Severity Scale

| Severity | Meaning |
| --- | --- |
| Critical | Blocks onboarding, risks cross-tenant exposure, or allows unreviewed AI output to appear approved or client-facing. |
| High | Prevents a core first-time workflow such as client setup, review import, insight review, or report export. |
| Medium | Causes confusion, repeated steps, missing evidence, or slow completion but has a workaround. |
| Low | Minor wording, layout, or expectation issue that does not block progress. |

## Notes

- Record the user's first visible blocker, not only the final failure.
- Capture screenshots or short clips for confusing empty states, validation messages, missing evidence links, unclear approval status, or report export errors.
- Mark any AI insight friction with whether the issue involved confidence, source review references, approval status, or unsupported claims.
- Mark any data access issue with the expected agency, client, location, and role scope.
